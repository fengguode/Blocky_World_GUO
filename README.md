# Blocky World

A joyful voxel game with three modes: build, fight, and observe. It runs in a modern browser without a build step or external runtime assets, and keeps the offline single-player path.

## Offline single-player

Open `index.html` in a browser. This starts the game locally without contacting a server. Existing browser saves are migrated locally when the game recognizes the previous save format.

## Family LAN server

The Windows host needs Node.js installed. Double-click `start.bat` on the family PC and leave its console window open while the server is in use. It displays the local network address and, only before first setup, a one-time setup code.

On each device connected to the same home Wi-Fi:

1. Open the displayed address in a browser. On iPhone or iPad use Safari; **Add to Home Screen** is optional.
2. On first use, enter the one-time code shown only in the PC server window. Create the two profile names and enter each profile's already agreed PIN. The server stores salted PIN hashes on the PC; PINs are not included in the browser code or repository.
3. On later visits, select the profile and enter its PIN.

Each profile's saved world is stored separately under `.blocky-world-data/` on the PC. The folder is excluded from Git and is not served to browsers. Stopping the server invalidates active sessions; restart it manually with `start.bat`. If Windows Firewall blocks the connection, run `allow-firewall.ps1` on the PC while it is connected to a trusted home network; it adds a rule for the Private network profile only.

This service currently uses unencrypted HTTP on the home LAN. A device monitoring that network could capture a PIN or session cookie, so use it only on trusted home Wi-Fi. Do not enable router port forwarding or expose it to the internet. Internet access needs stronger account credentials and TLS first. GitHub Pages can host public static files, but cannot enforce the required server-side profile access or save private worlds; the game remains hosted on the family's PC.

Login and separate server-side profile saves are implemented. Live visits between profiles are still open work; a second player cannot yet join another profile's world.

## The three modes

**Play & Build** — Explore, break blocks, and place blocks. Flying starts enabled; use **FLY** to toggle and **▲▼** to move vertically. Pigs, sheep, and chicks wander nearby.

**Fight Arena** — Choose characters and fight in a generated arena. On a phone, the second fighter is computer-controlled; a connected controller can take over.

**Observe World** — See the world from different camera views and take a photo.

## Original characters

The roster includes Steve, Alex, Web Hero, Dolly, Stone Golem, and Fire Ninja. Keep every character visually original: use broad themes such as a friendly web-slinging hero or a cheerful imaginative doll, and avoid recognizable names, costumes, logos, faces, or signature details from existing franchises.

## Controls

On a phone or tablet, use the on-screen thumbstick to move, drag the right side to look, and use the large **BREAK / PLACE / JUMP / FLY** buttons. In a fight these become **HIT / SKILL / JUMP / FLY**. Controls support touch-only play.

On a desktop, use **WASD** to move, the mouse to look, left click to break, right click to place, **1–9** for the hotbar, **F** to fly, **J / K / L** for fight actions, **V** to switch between third- and first-person view, **F5** to change camera, **P** for a photo, and **F10** to pause.

A second local player can use a gamepad or arrow keys plus Numpad 1 / 2 / 3.

## World and saves

- The world is 200 × 200 blocks and 100 blocks tall. **Reset World** rolls a new seed.
- Terrain, textures, and sounds are generated by the game; it loads no external runtime assets.
- World edits, seed, player position, settings, and character picks save automatically. Offline saves remain in the browser; LAN profile saves stay on the PC.
- The server is built with Node.js built-ins and has no third-party runtime dependencies.

## Tests

The repository has an opt-in test runner. Run it only when requested:

```
node tests\run.js
node tests\run.js Meshing
node tests\run.js --verbose
node tests\run.js --list
```
